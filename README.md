# EBay Marketing and Promotions PHP SDK

PHP SDK for eBay Marketing & Promotions APIs.

## Covered APIs

- **Marketing V1** — promotions, campaigns, ads, item price markdown
- **Recommendation V1** — ad rate and listing quality recommendations

OpenAPI specs are in `specs/`. Implementation not yet started.
